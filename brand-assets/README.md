# 若水文化公开品牌素材库

供 Codex 与指定品牌项目取用、审阅的公开素材投影。包括若水文化、Emily Garden、ANNA&CO.、Cherry 11。

## 给 Codex 的入口

1. 先读本说明及 [公开素材检查报告](AUDIT.md)。
2. 从 [brands.json](brands.json) 读取固定品牌ID与Logo路径，从 [asset-manifest.json](asset-manifest.json) 查尺寸、格式、透明度、版本和SHA-256。
3. 优先选SVG或适合用途的WebP/PNG。不得重画、拉伸、旋转、改字形、改比例、擅自改色或添加效果。
4. `_drafts/` 里的8张头像均待确认；颜色提取值也仍为 `confirmed:false`。文件处理完成不代表品牌负责人批准或对外业务发布。

本公开库提供99份Logo格式/尺寸文件、8张头像草稿和8份Logo原始素材，不含官网源码、内部经营资料或执行记录。官网修改应在获得授权的官网项目中另行实施。

## 文件使用

- 图形四周至少留其可见高度的10%；头像草稿至少留20%。
- 通用最低高度为网页24px、印刷8mm。细字完整版需要更大尺寸并逐次检查；不能承诺24px副标可读。
- 深底或照片上使用原本存在的白版；ANNA/Cherry没有白版，必须保留原近白底板或另取经确认的透明原稿。
- Emily的黑色原生版本为50%黑，保留原opacity；不是实心黑。集团水纹SVG来自现有favicon，线宽1.55，不冒充其他线宽版本。
- 集团完整中文Logo仅原生477px，未放大成512/1024/2048；Anna只有1024/512，缺少足够像素时不放大。
- 官网旧Emily黑玫瑰保存在原稿区作来源对照，新VI以用户提供的四页PDF为优先依据。
- 原始文件名和字节保留。两个官网下载文件虽然名为.png，真实格式是JPEG，实际格式见manifest。
- 本库没有AI重画、AI放大或自动描摹的正式文件。WebP与PNG的可见像素及alpha已核对。
